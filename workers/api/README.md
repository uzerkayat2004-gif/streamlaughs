# Crowd Worker

Hono edge routes + one SQLite Durable Object per validated lowercase Twitch channel. Local development needs no account/login. Follow [setup and first-deploy commands](../../docs/crowd-setup.md), [API](../../docs/crowd-api.md), [threat model](../../docs/crowd-threat-model.md) and [manual checks](../../docs/manual-part4.md).

`pnpm --filter api dev` runs local Wrangler; `pnpm --filter api test` runs actual Miniflare Workers/WebSocket/SQLite/hibernation tests. `pnpm --filter api build` is a local Wrangler dry-run bundle, not a deployment. Production is deployed at https://streamlaughs-crowd.streamlaughs.workers.dev with crowd enabled, test traffic disabled, the fixed extension origin and the Vercel site origin. Its existing `v1` migration creates SQLite-backed Durable Objects on the free plan. Owner reads use short-lived channel-bound signatures, not the retired read secret. Follow [current production and simulator instructions](../../docs/production-part7.md); keep the keys out of source and extension builds.
