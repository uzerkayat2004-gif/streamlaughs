## UI and truthful data

- One yellow squircle, dark closed-eye arcs and a filled laughing mouth. Generated toolbar PNGs, app SVGs, favicon, welcome, recap and canvas use the same geometry. The text wordmark retains its underline curve without eyes. Yellow/coral/teal and tints; extension copy says fans. Glass/white overlay and launcher, tiny coral recording indicator, five live bars, personal laugh bounce, remembered drag and four-second fade remain compact.
- Popup face follows the main action, including ZIP update priority, channel start and active stop. Store installs keep browser-managed updates. Mic check and version remain in the footer.
- Stop saves immediately: summary, see recap, later and confirmed discard/keep it. Unread saved recaps get a streamer badge and toolbar dot. Merely browsing My streamers does not mark them read. Opening their story does. Dexie v3 marks old v1/v2 recaps read without deleting or changing their statistics; new saves start unread. All storage/protocol identifiers remain [internally compatible](internal-identifiers.md).
- Stories use saved duration, actual timestamped personal laugh events, filtered top phrases and positive-only reaction chips. Biggest minute is a rolling 60-second window, with the exact 60-second boundary excluded. Channel history and ordinal count include only streams up to the selected stream, not future streams. Usual means the mean laugh count of prior saved streams with this channel. Hourly figures use actual watched duration.
- The server stores concurrent fan peaks, not unique fan laugh totals or overlap between personal and fan events. Those requested fan facts cannot be reconstructed truthfully; that story is omitted. No fabricated X% or total derived from peaks. Zero-laugh/zero-word sessions have exactly one mic-check story. Zero-laugh PNG sharing is disabled at the UI and canvas API.
- My streamers uses canonical Twitch URLs/display names, stable palette hashes, inline totals and the most laughs/hour, actual per-stream sparkline bins, unread badges, and confirmed per-stream/whole-channel deletion. Offline initials are immediate; optional photos never block rendering.
- Optional connected profile lookup now also returns bounded public VOD metadata. Only the channel login is sent; no viewing dates, counts, words, IDs or audio. VOD time matching happens locally against created_at + duration. Missing/expired/unmatched VODs show session time only. Connect photos again in the small settings disclosure to refresh public replay metadata. Website session and owner secrets remain server-side.
- 1080×1920 canvas export uses the coral laughs theme, selected safe stats, optional cached public avatar and history ordinal. Missing chips are omitted. Preview/download/PNG clipboard/native file sharing/text fallback remain local. Synthetic screenshots and sample cards are labelled demo/test, not real user detections.
- Interaction transitions/entry animations are <=240ms and respect reduced motion. The requested ambient breath, recording pulse and five-second story progress timer are intentionally slow; reduced motion disables them/autoplay.

## Final manual acceptance (10–15 minutes)

- [ ] Download the website ZIP. Unzip it and **replace every file inside the same existing installed StreamLaughs folder** (the one with manifest.json). Avoid a nested extra folder. Keep that folder on disk.
- [ ] Open **chrome://extensions**, click **reload** on StreamLaughs, then **refresh the Twitch tab**. **Never click Remove.** Confirm popup/debug version 0.8.0, the fixed ZIP ID and your prior settings/recaps. The new face and glass panel should appear; an already open tab may offer the glass refresh note.
- [ ] Popup → test my mic → laugh or say “let’s go”. Check moving input and “heard you!”. If it fails, check Windows microphone privacy/default device and use the exact error shown. Alt+Shift+D on the overlay shows permission, tracks, frames, model scores, last filtered phrase and saved counts.
- [ ] On a real live Twitch stream, try a headset first, then speakers at a normal listening level. Laugh and say “let’s go”; confirm personal counts increase, and match the recap after stopping. Also leave only stream playback running: it should not count your reactions. Laptop acoustics, hardware DSP/AEC and physical device changes need this real test.
- [ ] Pause/resume, briefly mute/unmute, unplug/retry a mic, switch tabs (keeps recording), change channel (saves), then stop. Test see recap, later/unread badge, and discard → keep it/confirmed discard.
- [ ] Check popup at actual Windows 100% and 125% display scaling, overlay drag/collapse/fade, keyboard focus, touch recap halves and reduced motion. No clipping or controls hidden under the panel.
- [ ] Open My streamers: correct grouping, actual separate sparklines, delete confirmations, read badge clears only when the story opens. No zero-filled recap/share cards.
- [ ] Share a nonzero recap: preview, 1080×1920 download, PNG clipboard in a focused tab and native file Share where supported; text/download fallback remains available if OS sharing is unavailable.
- [ ] Optional: sign in on the website in your own Chrome, connect photos from the small history settings link. Check cached photo/initials offline and an existing public VOD link. No VOD is expected if archives are off, expired or unavailable. Website cookies blocked in the extension must leave initials usable.
