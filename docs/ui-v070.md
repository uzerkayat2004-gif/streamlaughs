## Behavior and privacy

- One rounded smile curve, transparent white/yellow SVGs, generated 16/32/48/128 icons. Regenerate with `node tools/generate-smile-icons.mjs`.
- 40px frosted launcher; 210px glass panel defaults above player controls. Drag the panel's handle or launcher; arrow keys also move them. Collapse returns to the launcher. Panel fades to 25% after four quiet seconds and wakes on hover/new personal laugh.
- UI feedback/bounce transitions take at most 240ms. The explicitly requested idle breath and tiny recording pulse are slow ambient cycles, not delayed interaction feedback. Reduced motion disables both.
- Existing Dexie v1 sessions/recaps upgrade in place. Only channel metadata/profile cache is added; saved statistics and settings remain. Groups use canonical watched Twitch URLs, falling back to the already-parsed login for legacy records.
- Optional public profile photos require website sign-in plus a separate host permission grant. No extra OAuth scopes, token storage or cookie-reading API. Only public channel logins go to the photo endpoint. No recap stats, words, dates or session IDs are uploaded. Photos cache locally; offline/denied/cookie-blocked requests use initials.
- Share cards are drawn on canvas, never page screenshots: selected stats and an optional cached public avatar. Audio, webcam, full transcript and raw audio never enter the PNG. Preview before download/copy/native share; cancelled/unsupported sharing leaves download/text available. Synthetic test fixtures are marked demo on exported cards.
