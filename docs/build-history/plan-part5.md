Provider visibility: Twitch sees streamer login; Vercel/Cloudflare see network metadata. Only the streamer auth cookie contains encrypted streamer identity/token; no viewer login or per-viewer tables are introduced. Store IDs can differ; keep both origins during migration. Existing path-derived installs change identity once and require explicit re-consent/reloading; browser-local records cannot transparently migrate across extension origins.
