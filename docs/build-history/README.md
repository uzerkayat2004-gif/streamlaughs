# Build history

The working notes from building StreamLaughs with Codex, kept for transparency.

- `plan*.md`: the plan for each build part.
- `verification-*.txt`: the commands Codex ran and their results, per part and per version.
- `manual-part*.md`: hands-on checks for real hardware, Twitch login and stores.
- `detection-*`, `fixes-*`, `audio-stutter-*`, `microphone-*`, `ui-*`, `polish-*`: what broke in real tests, how it was reproduced and how it was fixed.
- `release-part6.md`, `edge-store-part13.md`, `website-downloads-part8.md`, `popup-updates-part12.md`: packaging, store and update work.

These are historical notes. For how the project works today, start with the main [README](../../README.md) and the [technical guide](../technical-guide.md).
