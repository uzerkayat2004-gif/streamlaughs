# Real Twitch checklist · Chrome, then Edge

Use one unpacked debug copy, a playing Twitch channel and debug.html. Note browser version, mic, output device, volume/backend locally. Fake-device tests do not prove hardware behavior.

1. **Permission/start:** revoke mic permission and press popup Start. Welcome must open at allow mic. Allow; temporary tracks must end. Return and start via toolbar, then separately Alt+Shift+L. Expect one offscreen owner, warming → ready, mic/tab near 50 frames/s and uninterrupted normal-volume Twitch after closing popup.
2. **Headphones:** stay silent through stream laughter. Tab scores rise; your count stays unchanged. Laugh in several ≥1 s bouts separated by ≥2 s and check accepted reasons plus dot/popup counts. Try gasps, comfortable screams, normal speech and hype phrases. Inspect recap for actual words/counts/masked swears and no names/blocked terms. Record quiet/short laugh misses; current thresholds do not guarantee perfect recall.
3. **Speakers:** normal volume, echoCancellation true. Stay silent through ≥2 min of stream laughs/talk. Check correlations, both class scores and rejection reasons: rejection requires correlation plus matching tab class. React over the stream and check genuine reactions can pass. Repeat at a second volume; note false positives/misses. Headphones estimate must be unknown on constant/silent signals and remains a heuristic otherwise.
4. **Keyboard/noise:** type/use mouse for one minute without talking, with speakers and headphones. Note false personal events or Whisper hallucinations without changing gain.
5. **Pause/resume/stop:** pause from dot: streams/replay stay open, processing stops, inference becomes idle and worker ends. Resume from popup: same session, fresh warming/ready, no stale words. Stop: tracks, AudioContext, worker/models and offscreen owner end; exactly one recap saves.
6. **Mic loss:** unplug/disable/revoke during capture. Expect micLost, continued crowd/tab replay, no inference and retry toast. Reconnect/allow/retry: same session/tab track recovers. Plain silent samples from a hardware mute driver cannot reliably trigger micLost; document the device behavior.
7. **Consent:** turn listening off: both inputs/inference end, crowd stays. Re-enable: no capture until Start audio. Sharing must cause no network transport in Part 3.
8. **Lifecycle/UI:** switch tabs/apps—continue. Start another Twitch channel—save/stop first, capture second only. Separately close watched tab, change channel, leave Twitch and end browser sharing—stop/save once. Unrelated tabs must not stop capture. Theatre/fullscreen, resize/drag and snap persistence still work.
9. **Service-worker restart:** terminate only the service worker in extension DevTools. Offscreen capture/inference survives; status/counts resync without another media grant/warmup. Reloading the extension destroys offscreen too and is a different test.
10. **Load:** add normal laptop load. Drops remain bounded/countable; low power pauses words first, VAD/laugh scores continue. Remove load: after 20 healthy seconds <0.65 RTF, words may resume. Token deadlines cannot preempt an individual backend kernel; pause/Stop can terminate the whole worker. Debug elapsed time includes GPU waits, not just CPU use.
11. **Two-hour soak:** note process memory after warmup and at 15/30/60/120 min. Check hub rings ≤480,000 samples/source, VAD ≤32 jobs, speech ≤2 and transport ≤8. Watch model/driver allocations as well as bounded JS histories. This physical soak is not claimed as completed.
12. **Privacy/delete:** inspect extension network (local assets only), chrome.storage and Dexie after checkpoint/Stop. Expect metadata, numeric health, approved/masked labels, counts and timestamps; no PCM, transcript or debug state. Close/reopen debug to verify ephemerality. Delete my data still clears sessions/recaps/preferences.

Use [the recording guide](recording-guide.md) for a personal accuracy evaluation. Repeat this checklist in Edge; compiling Edge alone does not validate its physical audio routing.
